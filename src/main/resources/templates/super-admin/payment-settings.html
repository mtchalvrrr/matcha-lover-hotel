Set PAYMENT_MODE=PAYMONGO_TEST, PAYMONGO_SECRET_KEY using a PayMongo test key beginning with sk_test_, and PAYMONGO_WEBHOOK_SECRET using the signing secret for the registered webhook.

Register the public HTTPS endpoint /webhooks/paymongo in PayMongo and subscribe to checkout payment and refund events. Never enter API secrets into customer-facing forms or commit them to Git.

The application intentionally does not allow changing provider secrets from the website. Manage them through Codespaces secrets or the deployment environment.
