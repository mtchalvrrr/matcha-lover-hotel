Configure through repository secrets

Set PAYMENT_MODE=XENDIT_TEST, XENDIT_SECRET_KEY using a Xendit Development/Test Mode secret key, and XENDIT_WEBHOOK_TOKEN using the verification token from the Xendit dashboard.

After the application endpoint is available, register /webhooks/xendit as the webhook URL for Payment Session completed/expired events and refund succeeded/failed events. Use the public HTTPS Codespaces URL. Never put API credentials in website forms or commit them to Git.

This application intentionally does not allow changing provider secrets from the website. Manage them through Codespaces repository secrets or the local environment.
